# 智学网 AI 批改助手

以已验证的 **0.7.6 稳定基线 + 全自动提交修复（0.7.10）** 为基础。分享版只增加油猴菜单中的本地密钥设置及自动更新地址，不修改评分、粘贴、拖动和自动提交流程。

## 安装与分享

**[点击安装最新版](https://raw.githubusercontent.com/kingsley0849/zhixue-ai-grader/main/zhixue-ai-grader.user.js)**

1. Chrome 等浏览器先安装并启用 Tampermonkey（油猴）。
2. 点击上方安装链接，在油猴安装页确认。若浏览器只下载文件，可在油猴中导入一次该 `.user.js`。
3. 进入智学网阅卷页，打开浏览器油猴菜单，在本脚本下点击 **设置 DeepSeek API Key**，填写你自己的密钥。
4. 配置并保存本题题干、标准答案和评分细则。全自动模式需要再点 **开始批量**。

以后把上方安装链接发给别人即可。启用油猴自动更新且能访问发布地址时，油猴按其设置检查新版；更新不是发布后立即推送，通常要刷新阅卷页才运行新版。

只启用一个批改助手，避免重复面板或重复提交。自动流程为判分、填分、读回确认、提交一次、网站换卷后继续。模型要求人工核验或无法确认页面状态时会暂停，不盲目跳卷。

## 升级与本地数据

- 更新代码不包含个人密钥。每个人首次设置自己的密钥，以后保存在油猴本地存储，不用修改脚本源代码。
- 原旧版把密钥写在脚本代码中；从旧版升级到本分享版时，需要通过菜单设置一次。升级前请保存尚未保存的题目配置，并保管好自己的密钥。
- 脚本 `@name`、`@namespace` 和原评分标准、案例库的存储键保持不变。通过原脚本更新保留配置，不要卸载时清除数据。不同电脑或浏览器仍需自行备份、导入案例和配置。
- GitHub 只托管公开代码和更新文件，不接收密钥、评分标准或教师案例。密钥只用于向 DeepSeek 发起模型请求；作答内容会按脚本功能发送至模型服务判分。
- 本仓库不附带学生截图、教师确认数据或任何人的API密钥。模型评分仍可能出错，请按自己的阅卷要求核对使用。

## 自动更新

公开文件：

- `zhixue-ai-grader.user.js`：完整安装文件。
- `zhixue-ai-grader.meta.js`：版本与更新元数据。

安装链接、`@updateURL` 和 `@downloadURL` 均固定；新发布只提升版本号并更新这两份文件。官方机制见 [Tampermonkey 文档](https://www.tampermonkey.net/documentation.php?q=update_url)。

## 维护者发布新版

需要 Node.js；无需安装第三方依赖。

1. 在本地先验证稳定版修复；不要将私密密钥或学生资料复制到仓库。
2. 如需更新批改基线，将经过验证且不含密钥的代码放入 `src/baseline-0.7.10.user.js`，同时核对构建锚点。该文件名表示初始稳定基线。
3. 提升 `package.json` 中版本号。
4. 执行：

```sh
npm run build
npm test
npm run check
```

5. 检查变更后提交并推送到 `main`。不要只提高版本号而不更新完整安装文件；不要修改脚本身份或随意改动存储键。

当前分享版：0.7.11。这里只发布验证通过的版本，实验版本保留在本地。
